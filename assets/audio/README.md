# Notification audio

`adhan.wav` is a 29-second notification excerpt made from [Adhan.ogg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Adhan.ogg), dedicated to the public domain under CC0 1.0. The source recording is kept as `adhan-source.ogg`.

The excerpt stays under iOS's 30-second custom notification sound limit.
